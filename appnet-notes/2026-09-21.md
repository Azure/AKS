# AppNet Release Notes - 2026-09-21

> [Azure Kubernetes Application Network (AppNet)](https://learn.microsoft.com/azure/application-network) — changes shipped after August 10 through September 21, 2026. AppNet is in public preview.

### Announcements and retirements

* AppNet 1.3 (Istio 1.28) has been retired and is no longer supported.
* CVE-affected patches of AppNet 1.4 (Istio 1.29.1–1.29.5) and AppNet 1.5 (Istio 1.30.0–1.30.2) are no longer supported. If using self-managed upgrade mode, upgrade to a currently supported version following the [AppNet upgrade guide](https://learn.microsoft.com/en-us/azure/application-network/upgrades#initiate-an-upgrade).

### Features

* Joining a private AKS cluster to AppNet now requires the `Microsoft.AppLink/PrivatePath` feature to be registered on the subscription. Public AKS cluster joins are unchanged.

### Bug fixes

* Fixed an issue where reapplying an unchanged ARM template to a self-managed AppNet member without an explicitly pinned version could initiate an unexpected upgrade to the default minor version. The member now preserves its current AppNet version.
* Fixed an issue where retrying a previously rejected version update for a self-managed member could incorrectly pass initial validation and fail later in the operation. Version updates are now validated against the version currently running on the member.
* Fixed an issue where deleting a failed member could unintentionally remove an AKS cluster’s active AppNet membership if the same cluster had been used in a second AppNet join attempt. The active membership is now preserved.
* Fixed issues that could prevent AppNet or connected AKS cluster deletions from completing, including cascading member deletion and cluster-deletion reconciliation.
* Fixed an issue where AppNet operations could remain in progress indefinitely after an unrecoverable internal processing failure. Affected operations now fail cleanly so they can be retried.
* Deleting an AppNet resource while its creation or update is still in progress now returns clear retry guidance instead of starting a conflicting deletion.

### Component updates

* AppNet components were updated to address security vulnerabilities, including a denial-of-service vulnerability. No customer action is required.
* AppNet 1.4 has been updated to [Istio 1.29.7](https://istio.io/latest/news/releases/1.29.x/announcing-1.29.7/).
* AppNet 1.5 has been updated to [Istio 1.30.4](https://istio.io/latest/news/releases/1.30.x/announcing-1.30.4/) and promoted to the stable channel.
* AppNet 1.6 is now available on the rapid channel, using [Istio 1.31.0](https://istio.io/latest/news/releases/1.31.x/announcing-1.31/).
